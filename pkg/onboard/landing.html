orbit

Ubuntu 24.04 / 26.04 LTS · WSL2 · amd64

Install Orbit

Workstation CLI for onboarding, multi-repo sync, and the local dev stack. One binary, then a prompt before anything writes PATH.

Paste in a terminal
$ curl -fsSL orbit.manova.space | bash

Confirms before writing PATH.

Capabilities

Interactive safety prompts

Confirms before installing binaries or changing your shell PATH.

o shortcut alias

Optional short command that points at the same orbit binary.

Shell autocompletion

Tab completion for bash, zsh, and fish after install.

Multi-repo sync

Clone and keep a workspace in step from workspace.yaml.

After install

orbit doctor Check the workstation and repair what it can.
orbit init Clone the workspace from the manifest.
