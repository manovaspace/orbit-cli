## orbit audit merges

Report merged pull requests that bypassed the merge gate

```
orbit audit merges [flags]
```

### Options

```
      --days int   Days of merged pull requests to inspect (default 30)
  -h, --help       help for merges
      --remote     Read merged pull requests through gh
```
