## orbit self-update

Update the Orbit CLI binary to the latest release

### Synopsis

Checks GitHub releases for the latest Orbit CLI binary, displays release highlights, and performs atomic binary replacement.

```
orbit self-update [flags]
```

### Options

```
      --check   Check for updates without downloading or installing
  -h, --help    help for self-update
  -y, --yes     Automatically accept update confirmation prompt
```
