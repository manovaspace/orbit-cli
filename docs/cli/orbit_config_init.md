## orbit config init

Initialize default configuration file

### Synopsis

Creates the Orbit CLI configuration file (~/.config/orbit/config.yaml) with platform defaults.

```
orbit config init [flags]
```

### Options

```
  -f, --force   Overwrite existing configuration file with default values
  -h, --help    help for init
```

### Options inherited from parent commands

```
      --config string   Custom path to configuration file
```
