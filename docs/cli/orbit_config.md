## orbit config

Manage Orbit CLI configuration

### Synopsis

View, update, and manage persistent Orbit CLI configuration (~/.config/orbit/config.yaml).
Supports hierarchical resolution with environment variables and command-line flags.

### Options

```
      --config string   Custom path to configuration file
  -h, --help            help for config
```
