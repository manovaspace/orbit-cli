## orbit admin totp reset

Reset two-factor TOTP for a user and issue a fresh recovery grant

```
orbit admin totp reset <email> [flags]
```

### Options

```
  -h, --help            help for reset
      --json            Output recovery details as JSON
  -s, --server string   Orbit server URL
      --store string    Custom path to owner storage vault file
```
