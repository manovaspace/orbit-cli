## orbit config show

Display current configuration with secrets masked

### Synopsis

Displays configuration values loaded from ~/.config/orbit/config.yaml, with sensitive credentials masked.

```
orbit config show [flags]
```

### Options

```
  -f, --format string   Output format: yaml or json (default "yaml")
  -h, --help            help for show
```
