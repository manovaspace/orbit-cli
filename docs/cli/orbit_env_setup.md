## orbit env setup

Generate .env files from schemas and initialize .cursor/mcp.env

### Synopsis

Scans for .env.schema.yaml contracts and generates .env files populated with default values and strict 0600 permissions.

```
orbit env setup [path] [flags]
```

### Options

```
      --force   Overwrite existing .env files with schema defaults
  -h, --help    help for setup
```
